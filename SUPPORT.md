# Support

For a reproducible technical defect, use the repository’s Issues tab once the repository is published. Include release/app/engine identity, browser and device, steps, expected and observed behavior, and a minimal shareable pack or seed. Remove private data and unauthorized images.

Use the itch.io discussion board for ordinary questions, match stories and creator-hosted pack links once the page is available. There is no TacticMesh account, cloud-result recovery service or supported private security-reporting address in this release. Do not post credentials or private information publicly.

Export full local backups before clearing storage. Browser origin changes create a different local library; move data through export/import. Incompatible checkpoints cannot continue, although historical reports remain readable.
