Bring a pack.
Keep the control.

Pack creation and local execution are supported. Hosted remote execution is not.

Files remain on the user's device. Your agent may create original fictional rosters, package permitted assets and run the same local football engine when its own environment supports execution.

Copy this into your own agent, then describe the teams you want. A website address does not give an agent access to your local browser storage.

node tools/tacticmesh-cli.mjs validate --pack ./teams.json
node tools/tacticmesh-cli.mjs simulate --job ./match-job.json --out ./result.json
node tools/tacticmesh-cli.mjs tournament --job ./cup-job.json --out ./cup-result.json
